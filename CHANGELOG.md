# Changelog

## 1.2.3 (2026-10-11)
- Next Numbers shows the number Magento gives next for Magento numbering, instead of the last number used.
- Every Next Numbers cell says whether it is a custom format or Magento numbering.
- The Next Numbers table fits the settings page instead of scrolling in its own box.

## 1.2.2 (2026-10-09)
- Product listing, FAQ and user guide.

## 1.2.1 (2026-10-07)
- The grid backfill command works on Magento 2.4.7 and 2.4.8.
- README states the right softaware/module-core version.

## 1.2.0 (2026-10-07)
- Deleted Orders Log: keyword search by order number, admin user or customer e-mail (hashed ones too).
- Clearer Deleted Orders Log with an introduction, fewer default columns and status labels.
- Titled confirmation for "Delete Permanently"; "Unmark Test Order" mass action.
- Settings: both sections side by side, defaults in every comment, tidier Next Numbers table.

## 1.1.0 (2026-10-06)
- Requires softaware/module-core instead of module-base; menu and permissions move under "Softaware".

## 1.0.0 (2026-10-06)
- Custom order, invoice, shipment and credit memo numbers per store view, with a next-number preview.
- Order grid columns: items, coupon code, shipping country, order comment and test order.
- Test order flag, guarded order deletion (off by default) and a Deleted Orders Log.
- CLI commands to show the numbering and to fill the grid columns for existing orders.
